## 1. About This Experiment

This experiment implements, analyzes, and demonstrates **Message Authentication Code (MAC)** generation and verification using a shared secret key $K$. 

A MAC provides two fundamental cryptographic assurances:
1. **Data Integrity:** Proves that the payload $M$ was not altered, inserted, or corrupted in transit.
2. **Data Origin Authentication:** Proves that the payload was generated by a party possessing the shared secret key $K$.

### Supported Constructions:
- **CBC-MAC (AES-128):** Cipher Block Chaining mode using raw AES-128 with $IV = 0^{128}$ and PKCS7 padding.
- **CMAC (NIST SP 800-38B):** Cipher-based MAC with subkey derivation ($K_1, K_2$) over $GF(2^{128})$ preventing length-extension and padding-oracle vulnerabilities on variable-length messages.
- **Keyed-MAC:** Secret-prefix general MAC construction using $SHA\text{-}256(K \parallel M)$.

## 3. Input & Output Specifications

### Input Parameters:
- **MAC Construction:** `CBC-MAC`, `CMAC`, or `Keyed-MAC`
- **Secret Key ($K$):** 128-bit hexadecimal string (32 hex characters) or arbitrary UTF-8 passphrase (automatically hashed to a 128-bit key).
- **Message Payload ($M$):** Arbitrary plaintext or hex-encoded string.

### Output:
- **Authentication Tag ($T$):**
  - CBC-MAC: 128-bit tag (32 hex characters)
  - CMAC: 128-bit tag (32 hex characters)
  - Keyed-MAC: 256-bit tag (64 hex characters)
- **Step Breakdown:** Block-by-block XOR feedback chaining $T_i = E_K(P_i \oplus T_{i-1})$.
- **Verification Status:** `VALID` or `FAILED (Mismatch Detected)`.

## 4. Test Vectors & Documented Test Cases

### Test Case 1: Standard CBC-MAC Tag Generation
- **Algorithm:** CBC-MAC (AES-128)
- **Secret Key ($K$):** `2b7e151628aed2a6abf7158809cf4f3c`
- **Message Payload ($M$):** `Transfer $5,000 to Account #98412`
- **Expected Tag:** 32-character hexadecimal string
- **Verification Result:** `VALID`

### Test Case 2: CMAC (NIST SP 800-38B) Subkey Derivation & Tag
- **Algorithm:** CMAC
- **Secret Key ($K$):** `2b7e151628aed2a6abf7158809cf4f3c`
- **Message Payload ($M$):** `Transfer $5,000 to Account #98412`
- **Expected Subkeys:** $L$, $K_1$, and $K_2$ derived via left shift and $R_{128} = 0\text{x}87$.
- **Verification Result:** `VALID`

### Test Case 3: Active MITM Tamper Detection (Avalanche Effect)
- **Original Message:** `Transfer $5,000 to Account #98412`
- **Tampered Message:** `Transfer $95,000 to Account #98412`
- **Observed Behavior:** Recomputed MAC mismatches the received tag immediately.
- **Verification Result:** `FAILED (Tag Mismatch Detected)`
